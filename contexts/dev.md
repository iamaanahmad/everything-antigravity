# Antigravity Development Context

Mode: Active Antigravity development
Focus: Implementation, coding, building features within the Antigravity ecosystem

## Behavior
- Write code first, explain after
- Prefer working solutions over perfect solutions

1. Get it working
2. Get it right
3. Get it clean

- run_command for running tests/builds

- Use workflows for repeatable processes
